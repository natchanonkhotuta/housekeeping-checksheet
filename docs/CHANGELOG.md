# บันทึกการเปลี่ยนแปลง

## 1.1.0

จัดโครงสร้างโปรเจกต์ใหม่ แก้บั๊ก และเพิ่มการใช้งานข้ามเครื่อง

### แก้บั๊ก

**1. แม่บ้านเข้าหน้าพิมพ์ CHECK SHEET ไม่ได้เลย**
บทบาทแม่บ้านมีสิทธิ์ `print.self` แต่เมนูตรวจด้วย `can('print')` ซึ่งไม่รู้จักสิทธิ์แบบมีจุด
ทั้งที่หน้าพิมพ์เขียนรองรับกรณีแม่บ้านไว้แล้ว
อาการเดียวกันนี้ยังทำให้ **หัวหน้าแม่บ้านเปิดหน้าวันหยุด/วันลาไม่ได้** ทั้งที่มีสิทธิ์ `holiday.edit`
และ **หัวหน้า/ผู้บริหาร/ผู้บันทึก เปิดหน้าแม่บ้าน พื้นที่ รายการงานไม่ได้** ทั้งที่มีสิทธิ์ `.view`

แก้โดยแยกการตรวจสิทธิ์เป็น 2 ชั้น — `ROUTE_PERMS` + `canAny()` สำหรับ "เปิดหน้าจอ"
และ `can()` แบบตรงตัวสำหรับ "แก้ไข" พร้อมเพิ่มด่านตรวจสิทธิ์ใน `renderRoute()`
เพื่อกันการเข้าหน้าจอโดยตรงโดยไม่มีสิทธิ์

**2. สแกนใบเช็คงานข้ามเดือนไม่ได้**
`handleFiles()` โหลดตารางเฉพาะเดือนที่เปิดค้างอยู่ แต่ `extractMarks()` อ่านเดือนจากรหัสบนแผ่น
สแกนใบของเดือนอื่นจึงขึ้นว่า "ยังไม่มีตารางงาน…" ทั้งที่มีข้อมูลอยู่
แก้โดยให้ `applyCorners()` ถอดรหัสแผ่นก่อน แล้ว `await loadPlan()` ของเดือนนั้นก่อนถอดผล

**3. การตัดภาพช่องในหน้าตรวจผลสแกนช้ามาก**
`cropCell()` เรียก `getImageData(x, y, 1, 1)` ทีละพิกเซล ≈ 968 ครั้งต่อช่อง คูณด้วยหลายสิบช่อง
แก้โดยดึง `ImageData` ของทั้งภาพครั้งเดียวแล้วเก็บใน `WeakMap` — วัดได้ 31 ms ต่อ 40 ช่อง

**4. สำรองข้อมูลบนคลาวด์ได้ไม่ครบ**
`backupAll()` ในโหมดคลาวด์ดัมป์เฉพาะตารางที่โหลดไว้ในหน่วยความจำของ session นั้น
เดือนที่ยังไม่ได้เปิดดูจะหายจากไฟล์สำรอง
แก้โดยเพิ่ม `planIndex` ในข้อมูลหลัก บันทึกทุกครั้งที่ `savePlan()` และรวบรวมจากทั้ง
`planIndex` + แคชในเครื่อง + การ query ฝั่งคลาวด์

**5. หน้ากระดาษของใบเช็คงานรายวันผิดแนว**
CSS ตั้ง `@page` เป็น A4 แนวนอนไว้ตายตัว แต่ใบเช็คงานรายวันขนาด 190×265 มม. เป็นแนวตั้ง
พิมพ์ออกมาจึงล้นหน้า แก้โดยสลับ `@page` ตามชนิดเอกสารที่กำลังพิมพ์

### แก้เพิ่มระหว่างทาง

- **ใบตรวจรอบวัน/สัปดาห์ถูกตัวบล็อก pop-up ขวาง** — `printRound()` เปิดหน้าต่างใหม่ด้วย
  `window.open()` ซึ่งถูกบล็อกในหลายเบราว์เซอร์และในหน้าเว็บที่ฝังใน iframe
  เปลี่ยนมาพิมพ์ในหน้าเดิมผ่าน `printDocument()` แทน
- **ใบเช็คงานรายวันข้ามเดือนไม่แสดง** — `drawDailySheets()` ข้ามวันที่อยู่ในเดือนที่ยังไม่โหลด
  ตอนนี้โหลดทุกเดือนในช่วงที่เลือกให้ก่อน และจำกัดช่วงไม่เกิน 62 วัน
- **บัญชีแม่บ้านที่ไม่ได้ผูกข้อมูลแม่บ้าน เห็นงานของทุกคน** — ตอนนี้แจ้งเตือนให้ไปผูกก่อน
  และหน้าเพิ่มผู้ใช้บังคับให้ผูกเมื่อเลือกบทบาทแม่บ้าน
- **รหัสแผ่นบนใบเช็คงานเปลี่ยนเมื่อจัดลำดับพื้นที่ใหม่** — เดิมอ้างอิงลำดับแสดงผล (`order`)
  ทำให้ใบที่พิมพ์ไปแล้วอ่านผิดพื้นที่หลังกดปุ่ม ▲▼ เปลี่ยนมาอ้างอิงลำดับที่บันทึกไว้จริงแทน
- **ชื่อผู้ใช้ซ้ำเมื่อเพิ่มแม่บ้าน** — ตอนนี้ต่อเลขท้ายให้อัตโนมัติจนกว่าจะไม่ซ้ำ
- **`leaveDialog` พังถ้าแม่บ้านถูกลบไปแล้ว** — เพิ่มการตรวจก่อนอ่าน `mainAreaId`
- **`ผู้บันทึก`/`ตรวจไม่ผ่าน` ทำให้ประวัติผู้ปฏิบัติงานสับสน** — แยกฟิลด์ชัดเจน
  `by` = ผู้ปฏิบัติงาน · `rec` = ผู้คีย์ข้อมูล · `vby` = ผู้ตรวจสอบ · `src` = ที่มาของข้อมูล
- ล้างโค้ดที่ไม่ทำงาน — `forEach` เปล่าใน `dailyRows()`, `text-align` ซ้ำใน `.navitem`,
  หมายเลขหัวข้อซ้ำในคอมเมนต์, ตัวแปรที่ประกาศแล้วไม่ได้ใช้

### เพิ่มใหม่

- **โหมดเก็บข้อมูลแบบเลือกได้ 4 แบบ** — อัตโนมัติ / เก็บในเครื่อง / Supabase / REST API ของตัวเอง
  พร้อมปุ่มทดสอบการเชื่อมต่อ ปุ่มดึงข้อมูลล่าสุด และปุ่มส่งข้อมูลในเครื่องขึ้นส่วนกลาง
- **แคชออฟไลน์** — ทุกโหมดคลาวด์มิเรอร์ข้อมูลลง `localStorage` เสมอ
  เน็ตหลุดยังใช้ต่อได้ และดึงข้อมูลใหม่อัตโนมัติเมื่อกลับมาออนไลน์
- **ลบพื้นที่ / ลบแม่บ้าน / ลบผู้ใช้** พร้อมการตรวจการอ้างอิง
  และเสนอทางเลือกที่ปลอดภัยกว่า (ปิดใช้งาน / ตั้งเป็นพ้นสภาพ) เมื่อการลบจะทำให้ประวัติเสียหาย
- **คำใบ้แป้นพิมพ์ในหน้าคีย์ผลจากกระดาษ** — `1`=✓ `2`=✗ `3`=– `0`=ล้าง ลูกศรเลื่อนช่อง
- ส่งออก Excel ของรายงานเพิ่มคอลัมน์ ผู้คีย์ข้อมูล และที่มาของข้อมูล (คีย์มือ/สแกน)
- `build.sh` สร้างไฟล์เดียวจบสำหรับแจกจ่าย และเวอร์ชันสำหรับวางเป็น Artifact

### เปลี่ยนโครงสร้าง

แยกไฟล์เดียว ~2,600 บรรทัด ออกเป็น CSS 1 ไฟล์ + JS 13 โมดูลตามหน้าที่
`index.html` เหลือเพียงโครงและลำดับการโหลด
